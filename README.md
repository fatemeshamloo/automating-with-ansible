# 🎨 گالری‌های انیمیشن دار

مجموعه‌ای از گالری‌های تصاویر با انیمیشن‌های مختلف و جذاب

## 📁 فایل‌های موجود

### 1. `gallery-animation.html` - گالری کلاسیک
گالری اصلی با ویژگی‌های زیر:
- ✨ انیمیشن Fade In برای تصاویر
- 🔍 لایت‌باکس با امکان ناوبری
- 🏷️ فیلتر بندی بر اساس دسته‌بندی
- 📱 طراحی واکنش‌گرا (Responsive)
- ⌨️ پشتیبانی از کیبورد
- 👆 پشتیبانی از لمس (Touch)

### 2. `masonry-gallery.html` - گالری مازونری
گالری پیشرفته با امکانات:
- 🧱 چیدمان مازونری (Masonry Layout)
- 🌊 انیمیشن پارالکس (Parallax)
- 🎬 صفحه اصلی با انیمیشن گرادیانت
- 📊 نوار پیشرفت اسکرول
- 🎯 دکمه شناور بازگشت به بالا
- 🎨 افکت Mouse Trail
- 🔄 انیمیشن‌های تصادفی

### 3. `css-only-gallery.html` - گالری CSS خالص
گالری فقط با CSS شامل:
- 🃏 کارت‌های چرخشی (Card Flip)
- ⭕ گالری دایره‌ای چرخان
- 🌊 گالری موجی
- 🔍 گالری زوم
- 🎞️ گالری آکاردئونی
- 🎨 انیمیشن‌های CSS خالص

## 🚀 نحوه استفاده

### اجرای سریع
فقط کافی است فایل‌های HTML را در مرورگر باز کنید.

### تنظیمات
برای تغییر تصاویر، آدرس‌های موجود در کد را تغییر دهید:

```javascript
// مثال تغییر تصاویر
const galleryData = [
    {
        id: 1,
        src: 'آدرس-تصویر-شما.jpg',
        title: 'عنوان تصویر',
        description: 'توضیحات تصویر',
        category: 'دسته‌بندی'
    }
];
```

## ✨ ویژگی‌های خاص

### گالری کلاسیک
- **فیلتر دسته‌بندی**: امکان فیلتر کردن تصاویر بر اساس دسته
- **لایت‌باکس**: نمایش تصاویر در حالت تمام صفحه
- **انیمیشن ورود**: تصاویر با انیمیشن زیبا وارد صفحه می‌شوند

### گالری مازونری
- **پارالکس اسکرولینگ**: تصاویر با سرعت‌های مختلف حرکت می‌کنند
- **هیرو سکشن**: صفحه اول با انیمیشن گرادیانت
- **نوار پیشرفت**: نمایش درصد اسکرول صفحه

### گالری CSS خالص
- **کارت‌های چرخشی**: هنگام hover کارت‌ها می‌چرخند
- **گالری دایره‌ای**: تصاویر در دایره چرخان قرار دارند
- **گالری موجی**: تصاویر با الگوی موجی نمایش داده می‌شوند

## 🎨 تنظیمات رنگ

### تغییر رنگ‌های اصلی
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-color: #ff6b6b;
}
```

### تغییر انیمیشن‌ها
```css
/* تنظیم سرعت انیمیشن */
.gallery-item {
    transition: all 0.3s ease;
}

/* تغییر نوع انیمیشن */
@keyframes customAnimation {
    from { opacity: 0; }
    to { opacity: 1; }
}
```

## 📱 پشتیبانی از دستگاه‌ها

- 💻 **دسکتاپ**: تجربه کامل با تمام انیمیشن‌ها
- 📱 **موبایل**: طراحی واکنش‌گرا با تنظیمات مخصوص موبایل
- 📟 **تبلت**: تطبیق خودکار با اندازه صفحه

## ⚡ بهینه‌سازی عملکرد

- **Lazy Loading**: بارگذاری تصاویر هنگام نیاز
- **Debounced Scroll**: بهینه‌سازی رویدادهای اسکرول
- **CSS Hardware Acceleration**: استفاده از GPU برای انیمیشن‌ها

## 🔧 سفارشی‌سازی

### اضافه کردن دسته‌بندی جدید
```html
<button class="filter-btn" data-filter="new-category">دسته جدید</button>
```

### تنظیم انیمیشن‌های ورود
```css
.gallery-item:nth-child(n) {
    animation-delay: calc(n * 0.1s);
}
```

### تغییر چیدمان grid
```css
.gallery-grid {
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}
```
